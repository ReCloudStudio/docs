# ReCloud Studio Documentation

Public documentation site for **ReCloud Studio** (worldexecute.me / recloud.studio).

Built with [Starlight](https://starlight.astro.build/) (Astro-based docs framework).

## Development

```bash
bun install          # install dependencies
bun dev              # start dev server (localhost:4321)
bun run build        # production build (outputs to dist/)
bun run preview      # preview production build locally
```

## Content Structure

- **manifesto/** - 总纲 (Manifesto)
- **organization/** - 架构、角色与关系
- **conduct/** - 内部成员日常行为守则
- **security/** - 数据安全与隐私保护
- **open-source/** - 开源协议
- **brand/** - 品牌与身份保护
- **management/** - 上层管理组织行为规范
- **development/** - 项目管理制度与技术开发规范
