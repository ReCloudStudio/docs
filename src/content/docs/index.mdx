## 什么是 ReCloud Studio？

ReCloud Studio 是一个致力于开源软件开发的小型团队。

我们以用户价值为导向，优先打磨开发者体验。

<CardGrid stagger>
  <Card title="公开项目 100% 开源" icon="open-book">
    对外公开项目的代码公开可见，接受社区的监督与贡献（使用规则详见《开源协议》）。
  </Card>
  <Card title="社区驱动" icon="puzzle">
    我们依靠社区的力量推进项目，重大决策经公开讨论后由管理层表决。
  </Card>
  <Card title="公开构建" icon="eye">
    我们在公开透明的环境下构建软件，所有决策过程可追溯。
  </Card>
  <Card title="AGPL-3.0 协议" icon="code">
    我们所有对外公开的项目均采用 AGPL-3.0 协议，保障用户自由使用与分发的权利。
  </Card>
</CardGrid>
