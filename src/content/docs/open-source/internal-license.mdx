## 概述

ReCloud Studio 内部项目的代码采用 AGPL-3.0 协议许可，但访问权限仅限内部成员，因此不属于公开「开源」范畴。内部项目不对外分发或提供服务，AGPL-3.0 第 13 条的源代码公开义务暂不触发；若将来对外提供网络服务，则须满足该条要求。

> 说明：AGPL-3.0 本身是开源许可证，但「开源」还要求代码公开可获取。内部项目仅授权内部成员访问，对外不构成开源软件；其公开项目（见 [对外公开源代码](./public-license)）才是真正的开源项目。

## 内部项目特点

### 代码访问

- **访问范围**: 仅限 ReCloud Studio 内部成员
- **代码托管**: 使用内部 Git 仓库
- **权限管理**: 基于角色的访问控制

### 代码管理

- **代码审查**: 所有代码变更必须经过审查
- **分支管理**: 遵循统一的分支管理策略
- **版本发布**: 遵循语义化版本控制

## 内部成员权利

内部成员可在授权范围内开发、测试、学习内部项目代码，并对现有功能进行修改、修复缺陷与性能优化。

## 内部成员义务

成员须遵循项目代码规范，为新功能编写测试并及时更新文档；不得向外部人员泄露代码，须安全存储代码与凭证，发现安全问题立即报告。
