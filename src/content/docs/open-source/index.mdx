## 概述

ReCloud Studio 致力于开源软件的开发与推广。我们所有对外公开的项目均采用 GNU Affero General Public License v3.0 (AGPL-3.0) 协议。

对外公开项目的使用规则见 [对外公开源代码](./public-license)，内部项目的管理规范见 [对内公开源代码](./internal-license)。

## AGPL-3.0 协议简介

GNU Affero General Public License v3.0 是一个强 copyleft 开源协议，在 GPL-3.0 的基础上增加了网络交互场景下的源代码公开要求。

### 核心特点

| 特性 | 说明 |
|------|------|
| 代码公开 | 衍生作品必须开源 |
| 网络交互 | 通过网络提供服务也必须公开源代码 |
| 修改要求 | 修改后必须标注修改内容 |
| 相同协议 | 衍生作品必须使用相同的 AGPL-3.0 协议 |

### 与其他协议对比

| 特性 | AGPL-3.0 | GPL-3.0 | MIT | Apache 2.0 |
|------|----------|---------|-----|-----------|
| 代码公开 | ✓ | ✓ | ✗ | ✗ |
| 网络服务公开 | ✓ | ✗ | ✗ | ✗ |
| 商用允许 | 须开源 | 须开源 | 允许 | 允许 |
| 专利保护 | 有 | 有 | 无 | 有 |

## 使用我们的代码

### 您的权利

- **使用**: 可以自由使用我们的代码
- **学习**: 可以学习我们的代码实现
- **贡献**: 可以向我们贡献代码
- **分发**: 可以在遵守协议的前提下分发代码

### 您的义务

- **开源**: 衍生作品必须使用 AGPL-3.0 协议开源
- **声明**: 在使用我们的代码时，必须声明代码来源
- **保留版权**: 保留我们的版权声明
- **标注修改**: 如果修改了代码，必须标注修改内容
- **网络公开**: 如果通过网络提供服务，必须公开源代码

## 开源项目流程

1. **创建项目**: 在 GitHub 上创建项目
2. **选择协议**: 使用 AGPL-3.0 协议
3. **编写文档**: 编写 README 与贡献说明（各项目仓库内）
4. **发布项目**: 发布第一个稳定版本
5. **维护项目**: 持续维护和更新项目

## 常见问题

### Q: 我可以在商业项目中使用 ReCloud Studio 的代码吗？

A: 可以，但您的项目也必须使用 AGPL-3.0 协议开源。

### Q: 我可以在闭源项目中使用 ReCloud Studio 的代码吗？

A: 不可以。AGPL-3.0 要求衍生作品必须开源。

### Q: 我可以通过网络提供基于 ReCloud Studio 代码的服务吗？

A: 可以，但必须公开您的服务端源代码。
