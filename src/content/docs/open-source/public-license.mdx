## 概述

ReCloud Studio 所有对外公开的项目均采用 AGPL-3.0 协议。使用我们的开源代码前，请仔细阅读以下说明。

## 您的权利

### 使用权

您可以自由使用我们对外公开的源代码：

- **个人使用**: 可以用于个人学习和研究
- **教育使用**: 可以用于教育目的
- **商业使用**: 可以用于商业目的（但需遵守开源义务）

### 学习权

您可以学习我们的代码实现：

- **阅读代码**: 可以阅读和理解我们的代码
- **学习技术**: 可以学习我们使用的技术
- **参考实现**: 可以参考我们的实现方式

### 贡献权

您可以向我们贡献代码：

- **提交 PR**: 可以向我们的项目提交 Pull Request
- **报告问题**: 可以报告发现的问题
- **建议改进**: 可以提出改进建议

## 您的义务

### 开源义务

使用我们的代码，您必须：

- **AGPL-3.0**: 您的衍生作品必须使用 AGPL-3.0 协议
- **完整保留**: 完整保留我们的版权声明和许可证文本
- **标注修改**: 如果修改了代码，必须标注修改内容

### 网络公开义务

如果您通过网络提供基于我们代码的服务：

- **公开源代码**: 必须公开您的服务端源代码
- **提供下载**: 必须提供源代码的下载方式
- **相同协议**: 公开的源代码必须使用 AGPL-3.0 协议

## 使用示例

### 正确使用

```javascript
// 基于 ReCloud Studio 的代码
// 来源: https://github.com/ReCloudStudio/project-name
// 协议: AGPL-3.0

function myFunction() {
  // 您的代码（您的项目也必须使用 AGPL-3.0）
}
```

### 错误使用

```javascript
// 不要这样做：没有声明来源，且使用闭源协议
// 协议: Proprietary (错误！)
function myFunction() {
  // 基于 ReCloud Studio 的代码，但没有遵守 AGPL-3.0
}
```
