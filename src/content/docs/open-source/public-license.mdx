## 概述

ReCloud Studio 所有对外公开的项目均采用 AGPL-3.0 协议。使用我们对外公开的开源代码前，请仔细阅读以下说明。

## 您的权利

您可以自由使用、学习我们对外公开的源代码，用于个人、教育或商业目的（商业使用须遵守下方开源义务）；也可通过提交 Pull Request、报告问题或提出改进建议向我们贡献代码。

## 您的义务

### 开源义务

使用我们的代码，您必须：衍生作品使用 AGPL-3.0 协议开源，完整保留我们的版权声明与许可证文本，并在修改时标注修改内容。

### 网络公开义务

若您通过网络提供基于我们代码的服务，须公开服务端源代码，提供可获取完整源码的下载链接，且公开部分同样采用 AGPL-3.0 协议。

## 使用示例

### 正确使用

```javascript
// 基于 ReCloud Studio 的代码
// 来源: https://github.com/ReCloudStudio/project-name
// 协议: AGPL-3.0

function myFunction() {
  // 您的代码（您的项目也必须使用 AGPL-3.0）
}
```

### 错误使用

```javascript
// 不要这样做：没有声明来源，且使用闭源协议
// 协议: Proprietary (错误！)
function myFunction() {
  // 基于 ReCloud Studio 的代码，但没有遵守 AGPL-3.0
}
```
