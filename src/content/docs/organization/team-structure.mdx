## 团队组成

ReCloud Studio 的成员划分为内部核心团队与外部参与者两个层次，各层次的规模与准入方式待补充：

### 核心团队

核心团队负责组织的整体运营和管理，目前设两个职能组：

- **技术组**: 负责技术架构、开发、测试和部署，对内承担从设计到上线的工程闭环。
- **运营组**: 负责社区运营、内容运营与用户支持，衔接产品与使用者之间的日常沟通。

### 社区贡献者

社区贡献者是不在编但持续参与项目的外部成员。其参与形式并不限于单一身份——同一个人常同时做代码、文档或测试工作。成为贡献者的实际门槛是：至少有一处合并进主仓库的 PR（代码、文档或翻译均可），此后即可在 Issues 中认领任务并参与测试反馈。

### 用户社区

用户社区是产品的最终使用者，也是问题的一线来源。多数用户仅使用产品（普通用户），部分会主动在反馈渠道提出意见或复现 bug（活跃用户），少数会主动对外介绍项目（布道者）。社区贡献者与用户社区之间并无硬边界：一名活跃用户通过提交 PR 后即转为社区贡献者。

## 协作方式

### 异步协作

我们主要采用异步协作，协作工具与具体用法以各项目的 `CONTRIBUTING` 文档为准（GitHub Issues 用于任务与缺陷跟踪，Pull Requests 用于代码审查与合并，文档通过在线编辑与评论协作）。
