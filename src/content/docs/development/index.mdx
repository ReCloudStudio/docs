## 概述

ReCloud Studio 的开发规范涵盖项目管理与技术标准两个层面：前者规定项目生命周期、角色职责与协作工具，后者规定代码、版本控制、测试、文档、性能与安全的技术要求。

- [项目管理](./project-management)：项目生命周期、角色、工具链与最佳实践。
- [技术标准](./tech-standards)：代码、版本控制、测试、文档、性能与安全规范。

## 细分规范

- [贡献指南](./contributing)：准备工作、开发流程、PR 与 Issue 规范。
- [Git 提交规范](./git)：分支策略、提交信息、PR 与版本号。
- [命名规范](./naming)：文件、变量、函数、类、组件等标识符命名。
- [Markdown 格式规范](./markdown)：文档排版与工具链配置。
- [标点符号使用规范](./punctuation)：中英文混排与标点使用约定。
- [TypeScript 编码规范](./ts-style)
- [Go 代码规范](./go-style)
- [Python 代码规范](./python-style)
