## 概述

ReCloud Studio 管理层拥有下列权力。具体行使规范与限制见下方各节及 [义务与限制](/management/obligations)。各权力按角色分工如下：

| 角色               | 主要负责                     |
| ------------------ | ---------------------------- |
| 管理员（Director） | 人事、财务、代表、战略决策   |
| Tech Lead          | 技术决策                     |
| Community Lead     | 运营执行、社区规则、活动策划 |

## 角色分工

### 管理员（Director）

- 统筹管理层的整体运作
- 行使人事、财务与对外代表权
- 决定组织发展方向与重大合作

### Tech Lead

- 决定技术路线、架构与技术标准
- 审查技术方案并指导技术团队

### Community Lead

- 制定社区规则与运营策略
- 策划重大活动并处理用户关系
- 执行管理员（Director）交办的运营事务

## 权力清单

### 人事权（管理员 / Director）

管理员（Director）有权任命各团队负责人、核心团队成员，以及由其聘用的临时特别顾问（无固定管理职责）；对失职、严重违规成员，以及根据不信任投票结果，有权予以罢免；对违规成员有权给予警告、暂停权限乃至开除。

### 财务权（管理员 / Director）

管理员（Director）有权审批年度预算、重大项目预算与紧急支出预算，以及大额支出、重大采购和捐赠支出。具体额度与审批程序见 [义务与限制](/management/obligations) 的财务权限制。

### 决策权

| 归属               | 决策范围                             |
| ------------------ | ------------------------------------ |
| 管理员（Director） | 组织发展方向、重大合作事项、品牌战略 |
| Tech Lead          | 技术路线、技术架构、技术标准制定     |
| Community Lead     | 运营策略、社区规则、重大活动策划     |

### 代表权（管理员 / Director）

管理员（Director）有权代表组织对外发言、签约与合作洽谈，并参与行业交流、国际合作与学术交流。

## 权力行使规范

行使权力须合法合规、公平公正，重大事项公开透明并接受监督；不得滥用权力谋取私利、超越权限行使权力、歧视任何成员，或利用权力进行报复。具体限制见 [义务与限制](/management/obligations)。

## 监督机制

管理层的监督机制（定期报告、财务公开、独立审计与投诉机制）统一规定于 [管理规范](/management/#监督机制)，本章不再重复。
