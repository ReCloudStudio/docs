## 一、总则

### 1.1 目的

本行为准则旨在为 ReCloud Studio 社区建立明确的行为标准，确保所有参与者都能在友好、安全和公平的环境中协作。

### 1.2 适用范围

本行为准则适用于所有社区空间，包括但不限于 GitHub 仓库、官方邮箱与社交媒体频道以及面对面或虚拟活动。

### 1.3 基本原则

- **友善**: 以同理心和善意对待他人
- **尊重**: 尊重不同的观点、经验和背景
- **公平**: 所有参与者都应得到公平对待
- **透明**: 决策过程公开透明

## 二、预期行为

### 2.1 沟通规范

- 使用清晰、简洁的语言
- 优雅地给予和接受建设性反馈
- 尊重他人的意见和观点
- 保密他人的隐私信息

### 2.2 协作规范

- 承认错误并从中学习
- 关注对社区整体最有利的事情
- 积极参与社区讨论
- 尊重社区的多样性

### 2.3 代码贡献规范

- 遵守项目的代码规范
- 积极参与代码审查
- 为代码编写清晰的文档
- 遵守开源协议

## 三、不可接受的行为

### 3.1 禁止行为

- 任何形式的歧视、骚扰或欺凌
- 未经同意发布他人的私人信息
- 性相关内容或不受欢迎的骚扰
- 持续干扰社区讨论或活动
- 其他可能被合理认为不当的行为

### 3.2 禁止内容

- 侮辱性语言
- 不当内容
- 仇恨言论
- 暴力威胁

## 四、执行机制

### 4.1 违规处理

1. **警告**: 违规者将收到私人警告，说明违规行为以及预期采取的纠正措施。
2. **临时禁令**: 如果行为持续，该人可能会被临时禁止参与社区活动。
3. **永久禁令**: 如果行为严重或持续，该人可能会被永久驱逐出社区。

### 4.2 举报流程

1. **发送举报**: 发送邮件至 report@worldexecute.me
2. **保密处理**: 所有举报将被保密处理
3. **及时回复**: 社区维护者（管理员（Director）与社区负责人（Community Lead）共同担任）将在 72 小时内回复
4. **公正调查**: 对所有举报进行公正调查

## 五、附则

### 5.1 解释权

本行为准则的解释权归 ReCloud Studio 管理层所有。

### 5.2 修订历史

本行为准则将根据实际情况进行修订，修订历史将在官方文档中记录。

### 5.3 申诉机制

若对举报处理结果有异议，可在收到处理通知后 7 日内向 [management@worldexecute.me](mailto:management@worldexecute.me) 提交申诉，由独立审查小组（由与事项无利害关系的核心贡献者临时组成）复核并做出最终决定。社区维护者由管理员（Director）与社区负责人（Community Lead）共同担任。
