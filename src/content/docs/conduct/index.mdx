## 我们的承诺

我们致力于让我们的社区成为一个友好、安全和公平的地方。

我们致力于营造一个尊重和促进每个人的尊严、权利和贡献的环境，无论种族、民族、种姓、肤色、年龄、外貌、神经多样性、残疾、性别、性别认同或表达、性取向、语言、哲学或宗教信仰、国籍或社会出身、社会经济地位、教育或任何其他身份属性。

所有真诚参与并遵守本公约的个人都享有平等的参与权利。

## 预期行为

- 以同理心和善意对待他人
- 尊重不同的观点、经验和背景
- 优雅地给予和接受建设性反馈
- 承认错误并从中学习
- 关注对社区整体最有利的事情

## 不可接受的行为

- 任何形式的歧视、骚扰或欺凌
- 未经同意发布他人的私人信息
- 性相关内容或不受欢迎的骚扰
- 持续干扰社区讨论或活动
- 其他可能被合理认为不当的行为

## 执行

1. 违规者将收到私人警告，说明违规行为以及预期采取的纠正措施。
2. 如果行为持续或严重，该人可能会被临时或永久驱逐出社区。

## 适用范围

本行为准则适用于所有社区空间，包括但不限于 GitHub 仓库、官方邮箱与社交媒体频道以及面对面或虚拟活动。任何违反本行为准则的人都可能受到社区维护者的制裁或驱逐。

> 社区维护者由 **管理员（Director）与社区负责人（Community Lead）** 共同担任，负责受理举报与执行本准则。

## 举报

如果您遇到或目睹违反本行为准则的行为，请发送邮件至 [report@worldexecute.me](mailto:report@worldexecute.me)。所有举报将被保密处理，社区维护者将在 72 小时内回复。

## 申诉机制

若您对举报处理结果有异议，可在收到处理通知后 7 日内向 [management@worldexecute.me](mailto:management@worldexecute.me) 提交申诉，由独立审查小组（由与事项无利害关系的核心贡献者临时组成）复核并做出最终决定。

本页为行为准则概要，完整条款与执行细则请参阅 [社区行为准则](./code-of-conduct)。
